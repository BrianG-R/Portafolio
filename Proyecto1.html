SweetScape

Aplicación móvil desarrollada con Visual Studio 2022, .NET y Xamarin para optimizar la gestión de una pastelería mediante registros, CRUD e interfaces simples para dispositivos móviles.

Descripción

Gestión móvil para pastelería

SweetScape permite registrar clientes, productos y sucursales mediante un sistema CRUD. El proyecto se enfocó en una interfaz simple, adaptable a dispositivos móviles y fácil de utilizar para tareas frecuentes de gestión.

Características

Funciones principales

  • Registro y gestión de clientes.
  • CRUD completo para productos de la pastelería.
  • Administración de sucursales.
  • Interfaz móvil intuitiva y amigable.
  • Conectividad con bases de datos locales.
