Arduino ESP8266

Sistema basado en Arduino con capacidad de movimiento, controlado desde una interfaz web publicada por la placa ESP8266 en la red Wi-Fi local.

Descripción

Auto controlado por Wi-Fi

El dispositivo genera un servidor web al que se puede acceder desde la red Wi-Fi local. Desde esa interfaz es posible controlar el movimiento del auto usando un celular o computador, explorando conceptos de IoT y comunicación entre software y hardware.

Características

Funciones principales

  • Control remoto mediante red Wi-Fi local.
  • Movimiento bidireccional y control de velocidad.
  • Interfaz web accesible desde móvil o PC.
  • Servidor web integrado en la placa ESP8266.
  • Exploración de conceptos de IoT.
