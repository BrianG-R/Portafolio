Aplicación de escritorio

Gestión de Inventario

Sistema CRUD desarrollado en Java para registrar, editar, eliminar y consultar productos conectados a una base de datos MySQL.

Volver al portafolio Ver en GitHub
Rol
Desarrollo Java y base de datos
Stack
Java, MySQL, JDBC, Swing
Objetivo
Gestionar stock y registros en tiempo real

Galería

Interfaz y gestión de datos

Descripción

CRUD conectado a MySQL

La aplicación permite registrar productos, editar información, eliminar registros y consultar stock. Uno de los retos principales fue implementar una conexión estable entre Java y MySQL, junto con validaciones y manejo de excepciones para evitar errores durante la manipulación de datos.

Características

Funciones principales

  • Registro y edición de productos con validación de datos.
  • Eliminación y consulta de inventario en tiempo real.
  • Conexión a MySQL usando JDBC.
  • Interfaz gráfica desarrollada con Java Swing.
  • Manejo de errores y excepciones.
